Privacy Policy

Last updated: October 13, 2026

This Privacy Policy explains how Affiliate Command Centre ("the Project") may access, use, and handle information when its features are developed and used.

1. Current Project Status

Affiliate Command Centre is under development. Google account data is not accessed by this website simply by visiting it. Access to Google data would occur only after a user authorizes a separately configured integration and grants the requested permissions.

2. Information and Google Account Data

Depending on the features implemented and permissions granted, the Project may process Google Drive files or metadata that the authorized integration is permitted to access. The Project is intended to support affiliate workflow organization and related business operations.

The Project will not request access beyond what is needed for its enabled features. Users should review the Google authorization screen before granting access.

3. How Information Is Used

Information made available to the Project may be used to provide requested features, organize workflow information, troubleshoot errors, and maintain security. Google user data will not be sold or used for advertising.

4. Storage and Retention

Storage and retention depend on the integration and deployment configuration that is actually enabled. Before Google account data is connected, the operator must document where such data and any authorization tokens are stored, who can access them, and how they can be deleted. Users should not connect sensitive data until these arrangements are in place.

5. Sharing and Disclosure

Google user data will not be sold. Data will not be shared except as necessary to provide a user-requested feature, with an appropriately authorized service provider, when the user directs such sharing, or when disclosure is legally required. Any such handling must comply with applicable Google API policies.

6. Security

Reasonable technical and organizational safeguards should be applied to protect information from unauthorized access, disclosure, alteration, or loss. No method of storage or transmission can be guaranteed to be completely secure.

7. User Choices and Data Deletion

Users can choose whether to authorize Google access and can revoke access through their Google Account security settings. Revoking authorization may stop features that depend on it. Requests concerning data handled by the Project can be sent to the contact email below.

8. Changes to This Policy

This policy may be updated as the Project's functionality and data practices change. The latest version will be published on this page with an updated revision date.

9. Contact

For privacy questions or data-related requests, contact: affiliatecommandcentre@gmail.com
